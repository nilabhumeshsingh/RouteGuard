# Wi-Fi Mapping Engine

This module is the indoor Wi-Fi fingerprinting cartography tool used to map campus access points and collect signal strength datasets for RouteGuard's indoor localization engine.

## Overview
When scanning Wi-Fi at any location (e.g. `AB1 Room 204`, `Food Court`, `Library 2F`), this tool captures all visible `iBUS@MUJ` BSSIDs along with their signal strengths, frequency bands, and channels, storing them as key-value pairs in a single row per location.

## Features
- **Hardware WiFi Scanning**: Direct Linux `nmcli` integration to scan all visible AP BSSIDs and signal strengths in real time.
- **Single-Row Key-Value Fingerprints**: Maps all detected BSSIDs at a location into a single row under the assigned location name.
- **CSV & JSON Export**: Export collected fingerprints directly for database indexing or Supabase k-NN queries.
- **Fast Minimal UI**: Clean interface focused purely on rapid scanning, location tagging, and export.

## Indoor Positioning with Supabase (k-NN)

The exported JSON structure can be loaded directly into PostgreSQL/Supabase with `jsonb` or `pgvector` to compute Euclidean distance between a live scan and stored fingerprints:

$$\text{Distance} = \sqrt{\sum (\text{RSSI}_{\text{scan}} - \text{RSSI}_{\text{stored}})^2}$$

The closest location match identifies the user's exact room and floor during an emergency.

### Supabase SQL Implementation:

```sql
-- 1. Table schema
CREATE TABLE wifi_fingerprints (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    location TEXT NOT NULL,
    bssid_data JSONB NOT NULL,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. k-NN Matcher Function
CREATE OR REPLACE FUNCTION match_wifi_location(sample_scan JSONB, k_neighbors INT DEFAULT 3)
RETURNS TABLE (
    location TEXT,
    distance NUMERIC,
    matched_aps INT
) AS $$
BEGIN
    RETURN QUERY
    WITH diffs AS (
        SELECT 
            f.location,
            COUNT(s.key)::INT AS matched_aps,
            ROUND(SQRT(SUM(POWER(
                COALESCE((s.value->>'signal')::NUMERIC, (s.value)::NUMERIC, 0) - 
                COALESCE((f.bssid_data->s.key->>'signal')::NUMERIC, (f.bssid_data->s.key)::NUMERIC, 0),
                2
            )))::NUMERIC, 2) AS distance
        FROM wifi_fingerprints f
        CROSS JOIN jsonb_each(sample_scan) s
        WHERE f.bssid_data ? s.key
        GROUP BY f.id, f.location
        HAVING COUNT(s.key) >= 1
    )
    SELECT diffs.location, diffs.distance, diffs.matched_aps
    FROM diffs
    ORDER BY diffs.distance ASC, diffs.matched_aps DESC
    LIMIT k_neighbors;
END;
$$ LANGUAGE plpgsql;

-- 3. Query sample
SELECT * FROM match_wifi_location(
    '{"90:14:AF:5F:B1:10": 75, "FC:11:65:DF:CB:F0": 98}'::jsonb,
    1
);
```
